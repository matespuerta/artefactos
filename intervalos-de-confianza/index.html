Intervalos de confianza para la media

Población normal con desviación típica conocida. Mueve los deslizadores y observa cómo se estrecha o se ensancha el intervalo x̄ ± z·σ/√n.

La amplitud es proporcional a 1/√n: con 4 veces más datos, el intervalo mide la mitad.

El valor crítico y el nivel de confianza van ligados: z = Φ⁻¹(1 − α/2). Al mover uno se actualiza el otro.

Datos del ejemplo

La referencia es un valor cualquiera (por ejemplo 14 días) para comprobar si queda dentro o fuera del intervalo.

La línea vertical es la media poblacional supuesta (la x̄ del ejemplo). Cada barra es el intervalo de una muestra nueva; en naranja, los que no la contienen.

Qué observar

  • Sube n con z fijo: el intervalo se estrecha y la campana se concentra en torno a x̄.
  • Sube el nivel de confianza con n fijo: z crece y el intervalo se ensancha.
  • Para dejar fuera un valor de referencia, estrecha el intervalo: más n o menos confianza.
