Sistemas de ecuaciones · Método de Gauss

Problemas contextualizados estilo PAU, resueltos paso a paso por el método de Gauss con sistemas de ecuaciones.

Los coeficientes se generan al azar a partir de una solución conocida, de modo que cada problema tiene siempre solución verificable. Operaciones entre ecuaciones con enteros (sin fracciones intermedias) y simplificación de ecuaciones cuando es posible.
