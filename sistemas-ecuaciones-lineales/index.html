Regla de Cramer en sistemas 3×3

Si |A| ≠ 0, el sistema es compatible determinado y

x = Δx|A|,   y = Δy|A|,   z = Δz|A|

Δx es el determinante que resulta de cambiar en A la columna de x por la de términos independientes (y lo mismo para Δy y Δz). Los determinantes se calculan con la regla de Sarrus.

Discusión de un sistema 3×3 con un parámetro

Teorema de Rouché-Frobenius. Sean A la matriz de coeficientes, A* la ampliada y n = 3 el número de incógnitas:

  • rg(A) = rg(A*) = 3: compatible determinado (S.C.D.).
  • rg(A) = rg(A*) < 3: compatible indeterminado (S.C.I.), con 3 − rg(A) parámetros libres.
  • rg(A) < rg(A*): incompatible (S.I.).

El rango es el orden del mayor menor distinto de cero. Se calcula |A|, se buscan los valores del parámetro que lo anulan y, para cada uno, se estudian los menores de A y de A*.
