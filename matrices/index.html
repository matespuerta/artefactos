Suma y resta

Solo se pueden sumar o restar matrices de la misma dimensión (mismo número de filas y de columnas). Se opera elemento a elemento, cada uno con el que ocupa su misma posición.

(A ± B)ij = aij ± bij
  • Producto por un número: k·A multiplica todos los elementos de A por k.
  • Es conmutativa y asociativa; el neutro es la matriz nula O y la opuesta de A es −A.
Ojo con los signos: al restar un número negativo, 3 − (−3) = 6.

Multiplicación

A·B existe solo si el número de columnas de A es igual al número de filas de B. El resultado tiene las filas de A y las columnas de B.

(m×n)·(n×p) → m×p

Cada elemento se obtiene multiplicando la fila i de A por la columna j de B, término a término, y sumando:

cij = ai1b1j + ai2b2j + … + ainbnj
  • Es asociativa y distributiva. La identidad I es el neutro: AI = IA = A.
No es conmutativa: en general A·B ≠ B·A, e incluso puede que uno de los dos productos no exista.

Potencias

Solo tienen sentido para matrices cuadradas. Elevar a n es multiplicar la matriz por sí misma n veces:

A2 = A·A   A3 = A2·A   An = An−1·A

Para un exponente grande (A50, A2026…) se calculan A2, A3, A4… hasta descubrir un patrón: que aparezca la identidad (las potencias se repiten de forma cíclica) o que algún elemento crezca de forma regular.

Cuidado: (A+B)2 = A2 + AB + BA + B2, que en general no es A2 + 2AB + B2.

Determinantes

Solo existen para matrices cuadradas; el determinante |A| es un número.

Orden 2: |A| = a11a22 − a12a21

Regla de Sarrus (orden 3): se suman los productos de la diagonal principal y de los dos “triángulos” paralelos a ella, y se restan los de la diagonal secundaria y sus paralelos.

+ a11a22a33 + a12a23a31 + a13a21a32
− a13a22a31 − a11a23a32 − a12a21a33

Desarrollo por adjuntos: se elige una fila (mejor la que tenga más ceros) y |A| = Σ aij·Aij, con Aij = (−1)i+j·|Mij|.

  • |At| = |A| y |AB| = |A|·|B|.
  • Si hay una fila de ceros o dos filas iguales o proporcionales, |A| = 0. Intercambiar dos filas cambia el signo.

Matriz inversa

A−1 es la matriz que cumple A·A−1 = A−1·A = I. Existe solo si |A| ≠ 0 (matriz regular).

A−1 = 1|A| · (Adj A)t
  • Adjunto de aij: Aij = (−1)i+j·|Mij|, donde Mij es el menor que queda al tachar la fila i y la columna j.
  • Los signos (−1)i+j forman un tablero de ajedrez: + − + / − + − / + − +.
  • Pasos: determinante → matriz de adjuntos → traspuesta → dividir entre |A|.
Comprueba siempre: A·A−1 debe dar la identidad.

Ecuaciones matriciales

Entre matrices no se puede dividir. Para despejar X se multiplica por la inversa, y por el mismo lado en los dos miembros, porque el producto no es conmutativo.

AX = B → X = A−1B
XA = B → X = BA−1
  • Primero se agrupan los términos con X y se saca factor común usando la identidad: AX + X = (A + I)X.
  • La matriz que multiplica a X debe tener inversa (determinante distinto de 0).
Error típico: escribir X = B·A−1 cuando la ecuación es AX = B. El lado importa.
